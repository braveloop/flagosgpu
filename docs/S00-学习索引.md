## 命名与维护约定

`docs/` 中的中文学习资料采用全局唯一的 `SNN-中文主题.md` 编号，`S00` 固定为学习索引，后续编号按文档形成顺序递增；这个序号只是阅读与文件排序标识，不等同于七阶段编号。队名 `Bravegpuwinner` 等固有名称可以保留原文，导出 PDF 与生成脚本可放在中文用途目录中。文件重命名后必须同步更新站内链接，禁止保留指向不存在文件的链接。

完整基线成果应同时包含环境身份、完整 Level 3、4K/16K 重复基线、原始证据和边界结论；优化成果应完成实现、正确性与 fallback、完整 Level 3、两个吞吐场景，并形成保留或回滚决定，达到这类门槛后才建立一份全局编号的中文复现文档。raw CSV、日志、manifest、逐题结果和 trace 仍按实验 ID 归档，不单独占用学习文档编号；同一成果的后续补证据、失败复盘和官方平台复验回填原文档。“继续验证”不算新成果，不得因此新建文档或预建空文件。新增成果文档时必须同步更新本索引。

发生阶段性实质进展时更新阶段状态、文档状态和对应正文，性能数据则保留实验 ID、平台、场景及原始证据位置。BI-V150 与 C500 分开记录，4K/16K 和 Prefill/Decode 分开陈述；只有完整验收后才将阶段标为完成。文档若与当前源码、官方规则或实验结果不一致，应先修正文档状态与结论，再继续后续学习记录。
